# Sécurité et confidentialité — MVP
- Dépôt GitHub privé ; vérifier distinctement la confidentialité du GitHub Project.
- Aucun secret dans historique, Issues, captures, logs ou prompts.
- `.env` ignoré ; `.env.example` sans clé.
- Vérifier licences, crédits et conformité des données et médias.
- Ne pas envoyer de données privées d'un club à un LLM sans permission.
- Moindre privilège pour accès Github/Cursor.
- Aucune action payante ou publication publique sans validation.
- Avant démo : secrets, droits et mode sans internet à tester.
