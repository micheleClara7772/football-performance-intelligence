# Vision produit et critères métier
**Périmètre :** application centrée sur une équipe configurable ; pas de plateforme multi-clubs.
**Utilisateur :** staff technique. Les décisions restent humaines.

## Modules et preuves
- Dashboard collectif : rencontres réelles, résultats, tendances.
- Analyse tactique : métriques 1re/2e mi-temps, cartes et limites.
- IA : questions FR, réponses sourcées, abstention si données insuffisantes.
- Vidéo : séquences annotées reliées à la même rencontre, avec droits validés.
- Séances : objectifs, joueurs, durée, matériel, contraintes, exercices, variantes, édition.

**Scénario :** Maroc–Portugal, 10/12/2022 ; aucune conclusion tactique avant calcul.

## Parcours : 7 preuves
- [ ] Dashboard réel consultable.
- [ ] Match de référence sélectionnable.
- [ ] Comparaison des périodes sur métriques réelles.
- [ ] Indicateurs et méthode vérifiables.
- [ ] Séquence vidéo autorisée et pertinente.
- [ ] Réponse IA contextualisée et sourcée.
- [ ] Séance modifiable issue du constat.

**KPI : 0/7 étapes vérifiées.**
